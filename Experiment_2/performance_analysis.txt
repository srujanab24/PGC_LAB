3. ANALYSIS

Both parallel programming approaches produced the correct result.

Performance improved substantially when increasing the number of threads
from 1 to 4.

Four threads gave the lowest measured execution time for Pthreads and
OpenMP in this experiment.

Increasing the thread count beyond four did not provide further
improvement in these measurements.

Efficiency decreased as the thread count increased because speedup did
not increase proportionally with the number of threads.

The efficiency above 100% for Pthreads with one thread results from
measurement variation between the sequential and parallel runs.
